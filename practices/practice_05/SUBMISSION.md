# ДЗ 5. Две команды — одна фича: режимы игры и всплывающие подписи

Проект — Тетрис из ДЗ 4 (`practices/practice_04/tetris/`), существующий код (brownfield). Фича: три режима («Марафон», «Спринт 40», «Ультра 2 минуты») с рекордом у каждого и всплывающие подписи «Тетрис!», «Комбо ×N», «Подряд», «Уровень N», «Финиш!», «Время вышло» с бонусными очками.

## Демо

```bash
cd practices/practice_04/tetris && python3 -m http.server 5173
```

1. `http://localhost:5173/` — выбрать режим «Спринт 40» → «Начать игру»: в колонке время и «N из 40»; P — пауза, время стоит.
2. «Ультра 2 минуты» — обратный отсчёт; P → «К выбору режима» — выход без итога и рекорда.
3. `http://localhost:5173/tests/e2e/index.html` → «Запустить все» → «18 из 18 PASS», заголовок вкладки `e2e: PASS`. Сценарии гоняют настоящий `index.html` с детерминированным seed и ручными часами: финиш спринта, конец ультры, «Тетрис!», «Комбо ×2/×3», «Подряд», «Уровень N», рекорды, недоступное хранилище, пауза, регрессия A/B.

## Что не проверено вживую

Настоящие Tab/Enter/Пробел (e2e шлёт синтетические события), VoiceOver, системное «уменьшение движения», ультра 120 с по реальным часам, касания. CLI `specify` не запускался (политика безопасности агента), шаги `{SCRIPT}` выполнены вручную — см. `../practice_04/tetris/.specify/README.md`.
