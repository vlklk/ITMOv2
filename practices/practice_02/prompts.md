# Журнал экспериментов Практики 2

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Выбранный слабый артефакт Практики 1: [`../practice_01/tests_load.md`](../practice_01/tests_load.md) — две строки таблицы и заглушка «нагрузочное тестирование станет актуальным позже»
- Что в нём нужно улучшить: числовые пороги вместо общих слов, привязка каждого сценария к правилу из [`../practice_01/context.md`](../practice_01/context.md), артефакт-подтверждение у каждой строки, честное условие запуска вместо заглушки
- Как поймём, что изменение полезно: у каждого сценария есть числовой предел и артефакт; каждый порог выводится из правила (SEC-1, API-1, REL-1, OUT-1, OBS-1); другой инженер может запустить прогон и принять Pass/Fail без устных пояснений
