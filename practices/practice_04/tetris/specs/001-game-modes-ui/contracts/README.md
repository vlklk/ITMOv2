# Contracts: 001-game-modes-ui

| Контракт | Где | Кто владеет |
|---|---|---|
| API логики и рекорда (`MODES`, `createGame`, `advanceTime`, поля состояния, события, исходы, `readModeRecord` / `saveModeRecord`) | [`specs/shared/game-modes-contract.md`](../../shared/game-modes-contract.md) **§2** (v1.0, «Согласовано») | общий, обе команды; меняется только новой версией контракта |
| Хуки интерфейса для сквозных проверок (параметры URL, событие времени, DOM-хуки) | [ui-test-hooks.md](ui-test-hooks.md) | команда UI |

Интерфейс использует **только** API контракта §2 и не повторяет его здесь, чтобы не было двух источников истины. Реализация UI начинается после того, как логика 002 влита и `sh scripts/check.sh` проходит.
