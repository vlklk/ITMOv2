# Quickstart: проверка интерфейса режимов и подписей

Как убедиться, что фича 001 работает. Детали хуков — [contracts/ui-test-hooks.md](contracts/ui-test-hooks.md), API логики — [контракт §2](../shared/game-modes-contract.md).

## Предусловия

- Логика 002 влита: `src/game.js` экспортирует `MODES`, `advanceTime`, `createGame(seed, modeId)`; `src/record.js` — `readModeRecord`, `saveModeRecord`.
- Из корня проекта `practices/practice_04/tetris`.

## 1. Unit-тесты

```sh
sh scripts/check.sh
```

Ожидается exit 0; среди тестов — `tests/format.test.js` (`UI FR-007…`, `UI FR-008…`) и `tests/ui-contract.test.js`.

## 2. Сквозные проверки

```sh
python3 -m http.server 5173
```

Открыть `http://localhost:5173/tests/e2e/index.html` → «Запустить все».

Ожидается: все строки E0–E17 — PASS, итог «18 из 18 PASS», заголовок вкладки `e2e: PASS`, ошибок страницы нет.

Агент: MCP встроенного браузера — `preview_start` с `name: "tetris"`, перейти на `/tests/e2e/index.html`, нажать «Запустить все», прочитать итог (`get_page_text`), `read_console_messages` — без ошибок.

Один сценарий вручную: открыть iframe-URL сценария из колонки «параметры», например `http://localhost:5173/?seed=7&mode=ultra&clock=manual&gravity=off&storage=session`, и в консоли страницы `dispatchEvent(new CustomEvent("tetris:advance", { detail: { ms: 120000 } }))` после старта — видна подпись «Время вышло».
