# План дизайна: «Тетрадь в клетку»

## Предмет, аудитория, задача

- **Предмет.** Тетрис — игра из квадратов. Пажитнов придумал его в 1984 году в Москве как вариацию пентамино — головоломки, которую рисуют на клетчатой бумаге. Самый узнаваемый «материал» этого мира для русскоязычного игрока — школьная тетрадь в клетку с красной линией полей.
- **Аудитория.** Человек, который открыл страницу, чтобы сыграть пару партий: за ноутбуком с клавиатурой или с телефона.
- **Главная задача.** Сразу показать поле и дать начать игру одной клавишей или кнопкой. Счёт и следующая фигура читаются боковым зрением.

## Палитра

| Имя | Hex | Роль |
|---|---|---|
| Бумага | `#F2F6F9` | Фон листа. Холодный белый, не кремовый |
| Клетка | `#C9DDEA` | Линии сетки. Клетка листа = клетка поля |
| Чернила | `#22398F` | Текст, обводка поля, кнопки, фокус |
| Графит | `#555B66` | Второстепенный текст, подписи |
| Поля | `#D2475A` | Красная линия полей и пометки красной ручкой: «Игра окончена», пауза |

Фигуры — набор фломастеров: I `#3A7BD5`, O `#E8A317`, T `#8E4FC2`, S `#2F9B67`, Z `#D2475A`, J `#22398F`, L `#E5782F`. Порядок цветов — привычный игрокам (I голубая, O жёлтая, T фиолетовая…), но тона приглушённые, как у фломастера на бумаге, и у каждой клетки тёмный контур того же тона.

## Шрифты

- **Neucha** (Google Fonts, есть кириллица) — рукописный: заголовок «Тетрис», подписи на полях («очки», «уровень»), заголовки оверлеев. Это «почерк» тетради.
- **Golos Text** (Google Fonts, Paratype) — гротеск для цифр счёта (`tabular-nums`, 600), текста кнопок и подсказок. Две гарнитуры заметно разные: рукопись против набора.
- Шкала (кратна клетке): 3 клетки — заголовок, 1,25 клетки — значения, 0,8 клетки — подписи, 0,55 клетки — подсказки. Строчные буквы, без капса.

## Раскладка

Весь лист — сетка с шагом `--cell`. Поле, превью следующей фигуры и блоки боковой колонки стоят на этой сетке, поэтому клетки поля совпадают с клетками тетради: поле — это просто участок листа, обведённый ручкой.

```
 десктоп (cell = 28px)
 |  :|                                           |
 |  :|  Тетрис  (рукопись, 3 клетки)             |
 |  :|  ┌──────────┐   следующая                 |
 |  :|  │          │   ▢▢▢▢                      |
 |  :|  │  поле    │   очки        1 240         |
 |  :|  │  10×20   │   уровень     2             |
 |  :|  │          │   строки      14            |
 |  :|  │          │   ← → ↓ ↑ X ␣ P  (легенда)  |
 |  :|  └──────────┘                             |
   ^ красная линия полей

 узкий экран (cell = 22px, 360–520px)
 |:| Тетрис              |
 |:| ┌────────┐ след.    |
 |:| │ поле   │ ▢▢▢▢     |
 |:| │        │ очки     |
 |:| │        │ уровень  |
 |:| └────────┘ строки   |
 |:| [←] [↻] [→] [↓] [⤓] |  ← кнопки только для касаний
```

Выравнивание: всё по левому краю ячейки сетки; текст «пишется» на линиях клеток. Блок по горизонтали центрируется с округлением до целой клетки, чтобы сетка не съезжала.

## Принципы

1. **Одна смелая идея — сетка листа и есть поле.** Никаких рамок-карточек вокруг статистики: подписи написаны прямо на полях тетради.
2. **Красная ручка — только для событий.** Красный цвет появляется лишь на линии полей и в сообщениях «Пауза» / «Игра окончена», как пометка учителя.
3. **Тихая типографика.** Рукопись для подписей, набор для цифр. Без капса, без меток над каждым блоком сверх нужных.
4. **Движение по делу.** Одна декоративная анимация — подчёркивание заголовка «прорисовывается» при загрузке; оверлеи появляются коротким fade. `prefers-reduced-motion` всё это отключает.
5. **Доступность.** Видимый фокус (3px чернильная обводка с отступом), кнопки настоящие `<button>`, счёт в `aria-live`, контраст чернил к бумаге > 10:1.

## Что отклонено как шаблон

- **Аркадный неон**: почти чёрный фон, светящиеся блоки, пиксельный шрифт Press Start 2P — то, что получается для любого «сделай тетрис». Это и есть дефолт №2 из skill (тёмный фон + яркий акцент).
- **Терминал Электроники-60** (зелёный люминофор, моноширинный шрифт, `[]` вместо блоков): исторически точно, но опять тёмный фон + кислотный акцент и моноширинные подписи.
- **Набор SaaS-карточек** для счёта/уровня/строк: одинаковые скруглённые карточки с тенью. Вместо них — рукописные пометки на полях.
- **Капс-подписи «SCORE / LEVEL / LINES»** и моноширинные цифры — заменены строчной рукописью и `tabular-nums` в гротеске.
- **Кремовая бумага с терракотой** (дефолт №1): бумага у нас холодная голубовато-белая, акцент — красная линия школьных полей, а не терракота.
- **Конструктивистский плакат** (красный/чёрный/кремовый, клинья Лисицкого) — рассматривал как «советский» вариант, отклонил: близко к дефолту №1 и №3 и плохо служит игровому полю.

## Самопроверка плана

Если попросить «дизайн тетриса» ещё раз, по умолчанию выходит тёмная аркада с неоном. Тетрадь в клетку из этого ряда выбивается и вытекает из предмета: квадратные фигуры на клетчатой бумаге — то, как тетрис и пентамино рисуют от руки. Единственный риск шаблонности — рукописный шрифт ради «милоты»; поэтому рукопись только в подписях и заголовках, а цифры и кнопки набраны гротеском.

## Фича B: призрак, hold, рекорд

Новых цветов и шрифтов нет — всё из той же тетради.

- **Призрачная фигура — карандашная намётка.** Так в тетради сначала обводят клетки пунктиром, а потом закрашивают: на месте приземления — пунктирный контур цвета фигуры без заливки и без штриховки. Отличается от настоящих клеток и формой (пунктир), и весом (нет заливки), поэтому не путается с лежащими фигурами даже на пёстром поле.
- **Отложенная фигура — вторая пометка на полях.** Блок «отложенная» стоит сразу под «следующей», в том же превью 4×2 — две фигуры, с которыми игрок сейчас считается, рядом. Пока hold израсходован (до фиксации фигуры), превью бледнеет — как вычеркнутое карандашом; так видно, почему C сейчас не срабатывает. Пустое превью подсказывает, что нажать.
- **Рекорд — ещё одна строка в столбике пометок** («рекорд» под «строками»), тем же почерком и гротеском. Если `localStorage` недоступен, строки нет вовсе — без «—» и без извинений. Новый рекорд — событие, поэтому в итоге партии он отмечен красной ручкой.
- **Легенда клавиш уходит в сноску под полем.** В столбике пометок двадцать клеток высоты: следующая + отложенная + четыре значения занимают его целиком. Легенда — справочная информация, ей место внизу листа, как сноске: три колонки по две строки на линиях сетки. На касаниях вместо неё кнопки, и среди них новая «⇄» — отложить.

```
 десктоп
 |  :|  ┌──────────┐   следующая
 |  :|  │          │   ▢▢▢▢
 |  :|  │   ┌┐     │   отложенная
 |  :|  │   ┆┆     │   ▢▢
 |  :|  │  ┌┄┄┐    │   очки / уровень / строки / рекорд
 |  :|  └──┴──┴────┘
 |  :|  ← → сдвиг   ↓ вниз быстрее   ↑ X поворот
 |  :|  пробел …    C Shift отложить P Esc пауза
```

Проверка на шаблонность: типичный призрак — полупрозрачная копия фигуры или серая заливка; пунктирная намётка вытекает из «тетрадного» материала. Hold слева от поля (как в большинстве клонов) отклонён: поле стоит у красной линии полей, а все пометки пишутся справа, на полях.
