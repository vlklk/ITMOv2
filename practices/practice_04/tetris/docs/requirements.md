# Контракт: Тетрис

Браузерная игра без сборки и зависимостей. Открывается через `python3 -m http.server 5173` в корне проекта → `http://localhost:5173/`.

## Фича A — играбельный тетрис

| ID | Требование | Как проверяем |
|---|---|---|
| A1 | Поле 10×20. Семь фигур I, O, T, S, Z, J, L. Генератор «мешок из 7»: каждые 7 фигур подряд — все семь по одному разу. При одинаковом seed последовательность одинаковая | unit-тест |
| A2 | Сдвиг влево/вправо и поворот по часовой не выводят фигуру за стены и не накладывают её на занятые клетки. Если поворот невозможен на месте, пробуем сдвиги 0, −1, +1, −2, +2 по горизонтали (wall kick); если ни один не подходит — поворот отменяется | unit-тест |
| A3 | Мягкий спуск — +1 очко за клетку, жёсткий сброс — +2 очка за клетку и мгновенная фиксация | unit-тест |
| A4 | Фигура фиксируется, когда не может опуститься. Заполненные строки удаляются, строки сверху сдвигаются вниз. Очки за 1/2/3/4 строки за раз: 100/300/500/800 × уровень | unit-тест |
| A5 | Уровень = 1 + ⌊строки / 10⌋. Интервал падения: `max(80, 800 − (уровень − 1) × 70)` мс | unit-тест |
| A6 | Если новая фигура не помещается в точку появления — игра окончена | unit-тест |
| A7 | Управление: ←/→ сдвиг, ↓ мягкий спуск, ↑ или X поворот, Пробел жёсткий сброс, P или Esc пауза. Экран начала и экран «игра окончена» с кнопкой «Играть снова» | проверка в браузере |
| A8 | На экране: поле, следующая фигура, счёт, уровень, строки | проверка в браузере |
| A9 | Дизайн — по skill `frontend-design`: собственная визуальная идея, а не шаблон; работает от 360 px ширины; видимый фокус клавиатуры; `prefers-reduced-motion` отключает декоративную анимацию | скриншот через MCP браузера |

## Фича B — помощь игроку

| ID | Требование | Как проверяем |
|---|---|---|
| B1 | Призрачная фигура: контур в той позиции, куда упадёт текущая фигура при жёстком сбросе | unit-тест позиции + скриншот |
| B2 | Hold по C или Shift: текущая фигура откладывается, на её место приходит отложенная (или следующая, если отложенной ещё нет). Не чаще одного раза до фиксации следующей фигуры | unit-тест |
| B3 | Рекорд хранится в `localStorage` и показывается на экране. Если `localStorage` недоступен, игра работает без рекорда | unit-тест с подменой хранилища |
| B4 | Все сценарии фичи A продолжают работать | `sh scripts/check.sh` |
